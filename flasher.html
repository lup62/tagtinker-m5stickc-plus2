TagTinker Flasher

Flash TagTinker onto your M5StickC Plus2 — straight from this page, no software to install.

Browser not supported

Web-serial flashing needs Chrome, Edge or another Chromium browser on desktop (not Safari, Firefox, or iOS). Open this page there, or flash from the command line — see the README.

Before you start

1
Plug the M5StickC Plus2 into this computer with a USB-C data cable (not charge-only).
2
Click Connect & Flash, then pick the port named like CP210x / USB-Serial.
3
Keep it still while it writes (~30 s). It reboots into TagTinker on its own.
Flashing replaces whatever firmware is on the Stick (e.g. UIFlow). You can always reflash UIFlow later with M5Burner.

On the Stick, note the Wi-Fi network and password shown on screen (default pass tagtinker).
